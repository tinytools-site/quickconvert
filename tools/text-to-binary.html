How text becomes binary


Computers store everything as binary — sequences of 0s and 1s. Text is no exception: each character is first mapped to a number by an encoding standard, and that number is written in base 2. The dominant standard today is UTF-8, a clever variable-length encoding where common English letters use one byte (8 bits) and other scripts or emoji use up to four.


For example, the letter 'A' is code point 65, which in binary is 01000001. The string 'Hi' becomes '01001000 01101001'. Because UTF-8 is backward compatible with ASCII, plain English text converts exactly the way classic textbooks describe, while emoji and non-Latin scripts simply use more bytes per character.


This converter works at the byte level using UTF-8, so any text you paste — English, Arabic, Chinese, emoji — converts correctly and decodes back to the identical string. You can choose space-separated bytes for readability or a continuous stream of bits.


Binary converters are popular for learning how computers represent data, for puzzles and CTF challenges, and for quick demonstrations in classrooms. Paste your text, convert, and copy the result — all processing happens locally in your browser.

    
Frequently asked questions




How is text converted to binary?
Each character is encoded as UTF-8 bytes, and every byte is written as 8 binary digits. 'A' (byte 65) becomes 01000001.


Why is my emoji longer in binary than a letter?
UTF-8 uses 1 byte for basic Latin letters but up to 4 bytes for emoji and many non-Latin scripts. More bytes means more binary digits.


Can I decode binary back to text?
Yes — choose the binary-to-text mode. The input must contain only 0s and 1s with a total length that is a multiple of 8, and it must form valid UTF-8.


What does the 'no spaces' option do?
It outputs one continuous bit stream instead of separating each byte with a space — useful when another tool expects compact binary input.
