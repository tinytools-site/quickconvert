What is Base64 encoding?


Base64 is a way to represent binary data using only 64 safe text characters: A–Z, a–z, 0–9, plus '+' and '/'. It is used everywhere behind the scenes — email attachments, embedding images directly in web pages, API tokens and basic-auth credentials are all commonly Base64-encoded so they survive transport through systems that only handle plain text.


Encoding is not encryption. Anyone can decode Base64 instantly, so it provides zero secrecy — it only solves the problem of moving binary or special characters through text-only channels. Never use Base64 to 'protect' passwords or sensitive data; use real encryption for that.


This tool is Unicode-safe, which many simple converters are not. Characters like emoji or accented letters are first converted to their UTF-8 bytes and then encoded, so 'héllo 🌍' round-trips perfectly instead of producing garbled output. Decoding validates the input first and reports an error for malformed Base64 rather than guessing.


Typical uses include encoding a small snippet for a data URL, decoding a JWT payload segment to inspect its claims, or preparing credentials for an HTTP Authorization header. Paste your text, choose encode or decode, and copy the result — nothing leaves your device.

    
Frequently asked questions




Is Base64 encoding secure?
No. Base64 is an encoding, not encryption — anyone can decode it in seconds. It only makes binary data safe to transport as text. Never rely on it to hide passwords or secrets.


Why do some Base64 strings end with '='?
Base64 works in 3-byte groups. If the input length is not a multiple of 3, '=' padding characters are added at the end to complete the final group. They are normal and expected.


Does this tool handle emoji and accented characters?
Yes. The encoder converts text to UTF-8 bytes first, so any Unicode character — emoji, Chinese, Arabic, accented letters — encodes and decodes correctly.


My Base64 will not decode. Why?
The most common cause is missing padding or characters outside the Base64 alphabet (often from copy-paste adding line breaks or spaces). The tool strips whitespace automatically and tells you if the input is still invalid.
