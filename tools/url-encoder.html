What is URL encoding?


URLs can only safely contain a limited set of characters: letters, digits and a few symbols. Everything else — spaces, accented letters, emoji, characters like '&', '?' and '#' — must be percent-encoded, meaning each byte is written as a '%' followed by two hexadecimal digits. A space becomes %20, and 'café' becomes 'caf%C3%A9'.


Encoding matters whenever you build links by hand, pass data in query strings, or generate slugs. An unencoded '&' inside a parameter value would be misread as the start of a new parameter, silently corrupting your data. Browsers encode form submissions automatically, but developers working with APIs often need to do it manually.


This tool offers two operations: encode, which converts text into its percent-encoded form using UTF-8 (the web standard), and decode, which reverses the process. Decoding validates the input and reports an error on malformed sequences like a lone '%' at the end of the string, instead of producing garbage.


A practical tip: encode each query parameter value separately, not the whole URL at once — otherwise the '?', '=' and '&' characters that structure the URL would get encoded too and the link would break. Everything here runs locally in your browser.

    
Frequently asked questions




What does %20 mean in a URL?
It is a percent-encoded space. Each byte that is not allowed raw in a URL is written as '%' plus two hex digits — a space (byte 0x20) becomes %20.


Should I encode the whole URL or just the parameters?
Encode each parameter value separately. If you encode the entire URL, structural characters like '?', '=' and '&' get encoded as well and the link breaks.


What is the difference between encodeURI and encodeURIComponent?
encodeURIComponent encodes everything except a small safe set, making it right for parameter values. encodeURI leaves URL structure characters (?, &, #) intact, for encoding a full URL. This tool uses the stricter component encoding.


Why did decoding fail with an error?
The input contains a malformed percent sequence — for example a '%' not followed by two hex digits. Check for truncated or double-encoded text.
